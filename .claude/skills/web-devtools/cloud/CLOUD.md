# Browser Use Cloud Platform documentation

**Authentication:** Save API Key with `browser-use cloud login <key>` or use `BROWSER_USE_API_KEY` environment variable.

**Cloud Browser:** Connect with `browser-use cloud connect` (supports timeout, proxy, and profile options).

**API Calls:** Use `cloud v2` or `cloud v3` with GET/POST methods, plus polling via `cloud v2 poll <task-id>`.

**Typical Workflow:** Login → Connect browser → Perform tasks → Close connection.
