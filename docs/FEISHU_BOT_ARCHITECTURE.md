## 飞书 Bot 命令

| 命令 | 功能 | 示例 |
|------|------|------|
| `/dev <需求>` | 开发新功能 | `/dev 创建一个用户登录页面` |
| `/fix <问题>` | 修复 Bug | `/fix 修复登录按钮点击无反应` |
| `/review <代码>` | 审查代码 | `/review 审查 src/auth.ts` |
| `/status` | 查看任务状态 | `/status` |
| `/help` | 查看帮助 | `/help` |

## 安全机制

1. **飞书签名验证**: 验证请求来自飞书服务器
2. **白名单**: 只有特定用户可以使用 Bot
3. **只读模式**: 默认只读，需要明确授权才能执行写操作
4. **操作审计**: 所有操作记录日志
5. **确认机制**: 高风险操作需要二次确认

## 开发流程

1. **用户发送消息** → 飞书
2. **飞书 Webhook** → Bot Server
3. **Bot Server 验证签名** → 解析消息
4. **任务入队** → BullMQ
5. **Worker 执行任务** → Claude CLI
6. **结果推送** → 飞书消息
