## 一、认识 Hermes

Hermes（赫尔墨斯）是学者茶话会平台的智能助手，以一只可爱的学术小狗形象常驻在页面右下角。他不仅能回答学术问题、分析图片，还能在你疲惫时送上安慰、在你开心时一起庆祝。

| 特性 | 说明 |
|------|------|
| **常驻入口** | 页面右下角熊猫头像，任何页面随时唤起 |
| **智能对话** | 支持文字、图片多模态交流，流式回复 |
| **人格切换** | 7 种性格模式，适配不同场景 |
| **互动彩蛋** | 点击、拖拽、双击都有惊喜反应 |
| **管理员模式** | 社区运营专用分析模式（仅管理员可见） |

## 三、聊天功能

### 3.1 发送消息

- **输入文字**：在底部输入框打字，按 `Enter` 发送（`Shift + Enter` 换行）
- **自动展开**：输入框会根据内容自动增高，最多 4 行
- **清空对话**：点击右上角 🗑️ 按钮重置会话

### 3.2 上传图片

Hermes 支持**看图说话**，可以识别图片内容并回答相关问题：

| 方式 | 操作 |
|------|------|
| 📎 文件选择 | 点击输入框左侧「+」图标，选择图片 |
| 📋 粘贴 | 直接 `Ctrl+V` 粘贴剪贴板中的图片 |
| 🖱️ 拖拽 | 将图片文件拖入聊天面板 |

**图片处理流程**：
```
用户上传图片
    ↓
前端自动压缩至 1024px（保证速度）
    ↓
MiniMax VLM 生成图片文字描述
    ↓
Hermes 结合描述 + 用户问题生成回答
```

> 📸 **使用场景**：上传论文截图询问内容、上传公式图片请求解答、上传数据图表请求分析……

### 3.3 智能工具调用

Hermes 在后台接入了多种工具，当你表达特定意图时会**自动调用**：

| 你的意图 | 自动行为 |
|----------|----------|
| "搜索最新论文" | 调用 skills_list 查找搜索技能 |
| "访问这个网页 https://..." | 调用浏览器工具打开网页 |
| "运行这段代码" | 调用代码执行工具 |
| "列个任务清单" | 调用 todo 工具创建任务 |

工具执行时，聊天框会显示「正在使用 xxx...」状态提示。

## 五、管理员专属：社区管家模式

如果你是平台**管理员**，聊天面板顶部会出现模式切换栏：

| 模式 | 用途 |
|------|------|
| 💬 日常助手 | 普通问答模式 |
| 🛡️ 社区管家 | 社区运营分析专用 |

**社区管家**模式下，Hermes 专注于：
- 分析社区内容质量和用户活跃度
- 提供运营策略建议
- 评估帖子和讨论热度
- 生成社区健康度报告

> ⚠️ 普通用户无法看到此切换选项。

## 七、FAQ

### Q1：Hermes 会记住我吗？
每次对话是**独立的会话上下文**，刷新页面或清空对话后历史不会保留。但 Hermes 的拖拽位置和人格选择会保存在本地浏览器中。

### Q2：为什么有些页面没有Hermes？
在 `/admin`（管理后台）、`/profile`（个人资料）、`/settings`（设置）页面，Hermes 会自动隐藏，避免干扰操作。

### Q3：图片上传有大小限制吗？
前端会自动压缩图片至最大 1024px 边长、JPEG 质量 80%，一般不需要担心大小问题。但如果原始图片极大，可能需要稍等压缩完成。

### Q4：Hermes 的回答来源是什么？
当前主要基于 **MiniMax-M2.7** 大模型，图片理解通过 MiniMax VLM 实现。部分请求可能fallback到 ZCHAT 或 DeepSeek 以确保可用性。

### Q5：可以用语音和 Hermes 交流吗？
目前仅支持文字和图片输入，暂不支持语音。
