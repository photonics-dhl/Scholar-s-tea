## 一、环境诊断结论

经过实际登录服务器（10.72.212.33）测试，得出以下关键结论：

| 测试项 | 结果 |
|--------|------|
| 服务器是否有公网 IP | ❌ 无（10.72.212.33 为内网 IP） |
| 是否可直接访问外网 | ❌ 完全不能（8.8.8.8:53、1.1.1.1:443 均超时） |
| 是否有代理可用 | ✅ 有，127.0.0.1:7890（HTTP + SOCKS5） |
| Cloudflare Tunnel | ❌ **不可行**（cloudflared 不支持代理，且 7844 端口被墙） |
| ngrok | ✅ **可行**（已在运行 cardserver，走 443 端口穿透代理） |
| LocalTunnel | ✅ **可行**（刚验证成功，走 443 端口） |
| frpc (SOCKS5 代理) | ✅ **理论可行**（frp v0.52+ 支持 `transport.proxyURL`） |

### 为什么 Cloudflare Tunnel 失败了？

1. **cloudflared 不支持 HTTP/SOCKS5 代理**：它是 Go 程序，直接发起 syscall，不走 libc
2. **proxychains 对 Go 程序无效**：proxychains 通过 LD_PRELOAD 拦截 libc connect()，Go 绕过 libc
3. **边缘节点 7844 端口被防火墙封锁**：不管是 TCP (http2) 还是 UDP (quic)，均 timeout
4. **服务器只能通过 7890 代理访问 80/443**：其他端口全部被拦截

> ⚠️ 除非网管开放 7844 端口出站，否则 Cloudflare Tunnel **在当前网络环境下完全不可用**。

## 三、方案一：ngrok（已验证可行，推荐）

### 现状

服务器上已有 ngrok 在运行：
- 配置路径：`/data/home/zju321/.config/ngrok/ngrok.yml`
- 当前 tunnel：`cardserver` → `https://colony-party-unpledged.ngrok-free.dev`
- 映射：`localhost:5000`（Python 服务）

### 方案 A：ngrok 免费版（零成本，临时域名）

ngrok 免费版可以同时配置 **多个 tunnel**（在一个 yml 里），但限制：
- 同时只能有 **1 个 ngrok 进程**在线
- 40 连接/分钟
- **不支持自定义域名**（只能用 `*.ngrok-free.dev`）
- 每次重启域名可能变化

**如果你只是想临时让 Scholar's Tea 能被外网访问**，可以直接修改 ngrok.yml：

```yaml
version: 3
agent:
  authtoken: 你的_token
tunnels:
  cardserver:
    addr: 5000
    proto: http
  web:
    addr: 3002
    proto: http
  socket:
    addr: 3001
    proto: http
```

启动：
```bash
cd /data/home/zju321/.config/ngrok
./ngrok start --all
```

> 注意：这会导致原来的 `cardserver` 域名变化，且 web/socket 的域名也是临时的。

### 方案 B：ngrok 付费版（$8/月，自定义域名 ⭐推荐）

升级到 **ngrok Basic（$8/月）** 后：
- 支持 **自定义域名**（绑定 428312321.xyz）
- 支持 **保留域名**（域名固定不变）
- 支持 **多个在线 tunnel**
- WebSocket 原生支持（Socket.io 可用）

**实施步骤**：
1. 登录 [dashboard.ngrok.com](https://dashboard.ngrok.com) 升级 Basic 计划
2. 在 Dashboard → Domains → 添加 `scholars-tea.428312321.xyz`
3. 修改 ngrok.yml：
   ```yaml
   version: 3
   agent:
     authtoken: 你的_token
   tunnels:
     web:
       addr: 3002
       proto: http
       domain: scholars-tea.428312321.xyz
     socket:
       addr: 3001
       proto: http
       domain: socket.428312321.xyz
   ```
4. 在 Cloudflare DNS 添加 CNAME：
   - `scholars-tea` → CNAME → `你的.ngrok.io`（ngrok 会提示）
   - `socket` → CNAME → `你的.ngrok.io`
5. 启动：`./ngrok start --all`

**优点**：配置简单，已验证在你的网络环境下能工作  
**缺点**：$8/月，长期累计费用

## 五、方案三：frp + 廉价 VPS（国内高速，长期）

### 为什么这个方案可行？

虽然服务器不能直接访问外网，但 frp 客户端（frpc）**原生支持 SOCKS5/HTTP 代理**！

frpc 配置示例：
```ini
[common]
server_addr = 你的VPS公网IP
server_port = 7000
token = your_token
transport.proxyURL = socks5://127.0.0.1:7890

[web]
type = http
local_port = 3002
custom_domains = scholars-tea.428312321.xyz

[socket]
type = http
local_port = 3001
custom_domains = socket.428312321.xyz
```

frps（服务端）配置：
```ini
[common]
bind_port = 7000
token = your_token
vhost_http_port = 80
vhost_https_port = 443
```

### VPS 推荐

| 厂商 | 配置 | 价格 | 备注 |
|------|------|------|------|
| 腾讯云轻量 | 2C2G 4M | ~¥100/年（新用户） | 国内线路，速度最好 |
| 阿里云轻量 | 2C2G 3M | ~¥108/年（新用户） | 国内线路 |
| Racknerd | 1C1G 1Gbps | ~$10/年 | 国际线路，性价比 |

**优点**：国内速度快，完全可控，一次投入长期可用  
**缺点**：需要购买 + 维护 VPS，前端需要配置 SSL（Let's Encrypt）

## 六、方案四：Sakura Frp（樱花穿透，国内免费节点）

Sakura Frp 是国内免费的 frp 公共服务，提供国内节点，速度较快。

### 特点

- 免费额度足够小型项目使用
- 国内节点延迟低
- 支持 HTTP/HTTPS/TCP/UDP
- **支持自定义域名**（需域名备案或选择非内地节点）

### 是否可行？

Sakura Frp 的客户端就是 frpc，frp v0.52+ 支持 `transport.proxyURL`：
```ini
[common]
server_addr = 某个樱花节点
server_port = 某个端口
transport.proxyURL = socks5://127.0.0.1:7890
```

**理论上可行，但尚未实测**。如果 ngrok 付费版预算不足，Sakura Frp 是一个值得尝试的免费替代。

官网：[www.natfrp.com](https://www.natfrp.com)

## 八、针对 Scholar's Tea 的配置要点

无论选择哪个方案，以下配置需要更新：

### 1. Socket.io WebSocket

ngrok、LocalTunnel、frp 均原生支持 WebSocket，无需额外配置。

### 2. 跨域 CORS

修改 `server/src/index.ts`：
```typescript
cors: {
  origin: [
    'http://localhost:3000',
    'http://localhost:3002',
    'https://scholars-tea.428312321.xyz',   // 你的新域名
    'https://socket.428312321.xyz',
  ],
  credentials: true,
}
```

### 3. 环境变量

```env
NEXTAUTH_URL=https://scholars-tea.428312321.xyz
SOCKET_SERVER_URL=https://socket.428312321.xyz
NEXT_PUBLIC_APP_URL=https://scholars-tea.428312321.xyz
```

### 4. NextAuth OAuth 回调

在 GitHub/Google/飞书开发者后台添加：
```
https://scholars-tea.428312321.xyz/api/auth/callback/github
```
