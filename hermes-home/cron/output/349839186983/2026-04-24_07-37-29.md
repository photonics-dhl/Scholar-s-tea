## 常见坑

### 坑 1：Nearfield 搜不到论文（0篇）
- 原因：ArXiv 关键词用 AND 连接太严格
- 修复：`search_by_category` 中 `query = "(" + " OR ".join(keywords)` 用 OR 扩大召回

### 坑 2：主卡片显示 "50篇新论文"
- 原因：`build_domain_cell` 中 `displayed` 变量在 fallback 之后才定义
- 修复：把 `displayed = min(len(papers), 3)` 移到 `trend` fallback 之前

### 坑 3：MiniMax 只分析有 arxiv_id 的论文
- 原因：`batch_analyze` 里有 `if p.get("arxiv_id")` 过滤，PubMed/Tavily 被跳过
- 修复：移除该过滤条件，所有来源都分析

### 坑 4：无 analysis 论文被发送
- 原因：解析失败时论文仍被发送
- 修复：`search_and_enrich` 返回前过滤 `p.get("analysis")`，无分析则重试（最多 2 次，top_n × 2）

### 坑 5：send_card 的 payload 结构（已修）
- 原因：`send_card` 里用了 `data=json.dumps(payload)` 双重编码，但飞书要求 `json=payload`
- 状态：代码已修复，使用 `requests.post(..., json=payload)`

### 坑 6：Feishu 卡片 schema 格式（最常踩）
- 错误：`{'schema': 'interactive', 'elements': [...]}` — 飞书报 `unknown schema: interactive`
- 正确：`{'schema': '2.0', 'body': {'direction': 'vertical', 'elements': [...]}}`
- 注意：`header` 在顶层而非 `body` 内；`config.update_multi` 可选
- 示例：
  ```python
  card = {
      'config': {'update_multi': True},
      'schema': '2.0',
      'body': {'direction': 'vertical', 'elements': elements},
      'header': {'title': {'tag': 'plain_text', 'content': '标题'}, 'template': 'blue'}
  }
  ```

### 坑 7：卡片内链接格式
- 正确（markdown）：`{'tag': 'markdown', 'content': "<a href='{url}'>🔗 来源链接</a>"}`
- 错误（div/text/a）：`{'tag': 'div', 'text': {'tag': 'a', 'href': url}}` — 飞书报 `mismatched type`
- 注意：URL 中含 `?uri=` 或下划线 `_` 在 div/text/a 结构中会导致 JSON 解析崩溃，markdown 格式则无此问题

### 坑 8：URL 链接在非 ArXiv 论文中被忽略
- 问题：`build_paper_detail` 和 `build_paper_elements` 只对有 `arxiv_id` 的论文加链接
- 修复：添加 `elif paper.get('url')` 分支，使 Tavily/PubMed/Crossref 等来源也能显示来源链接
  ```python
  if arxiv_url:
      lines.append(f"<a href='{arxiv_url}'>🔗 {arxiv_id}</a>")
  elif paper.get("url"):
      lines.append(f"<a href='{paper['url']}'>🔗 来源链接</a>")
  ```
