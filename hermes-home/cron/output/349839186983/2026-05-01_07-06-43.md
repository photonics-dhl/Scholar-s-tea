### MiniMaxAnalyzer 架构（2026-04-24 重大修正：热备→主分析引擎）

**背景**：MiniMax `MiniMax-ablo-Text-01` 不是 JSON 模式模型，约 40% 的论文分析因自然语言拒绝或部分 JSON 输出导致 `_parse_analysis` 失败返回 `{}`，论文被丢弃。这是导致 8 个领域无法全部达标 ≥3 篇的核心原因。

**2026-04-24 架构修正（实测验证）**：

```
analyze_paper()  ← 核心调用入口
  ├─ DUCKCODING gpt-5.4（Primary，✅ JSON mode）
  │    ├─ 200 + parse 成功 → 返回结果
  │    └─ parse 失败 → 切换 MiniMax
  └─ MiniMax M2.7（Fallback）
       ├─ 200 + parse 成功 → 返回结果
       └─ 失败 → 返回 {}（论文丢弃）
```

**为什么 DUCKCODING 是 Primary 而不是热备**：
- DUCKCODING `gpt-5.4` + `response_format: {"type": "json_object"}` = 接近 100% Parse 成功率
- MiniMax `MiniMax-ablo-Text-01` 非 JSON 模式 = ~60% Parse 成功率（40% 论文被丢弃）
- 实测效果：8/8 达标（429s）vs 旧架构 4/8 达标（811s）
