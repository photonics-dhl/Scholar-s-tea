📖 **超快光学知识 — 模块1：FROG（频率分辨光学门）**

---

🔬 **原理 | Principle**

FROG = Frequency-Resolved Optical Gating

核心思想：用被测脉冲自身（或其复制）作为"光学门"，对脉冲进行时域切片，然后对每个延迟位置测量光谱。

**非线性门机制（SHG-FROG，最常用）：**
- 脉冲被分束器分成两束：Gate beam + Signal beam
- 两束在非线性晶体（BBO）中重合，产生二次谐波（Second Harmonic Generation, SHG）
- SHG信号强度 ∝ I(t)·I(t − τ)，其中τ是延迟
- 通过光谱仪测量每个延迟τ对应的SHG光谱 → 得到 **FROG trace**: S(ω, τ)

**为什么是二维trace？**
- 传统自相关仅测量总强度随延迟变化（一维AC trace），丢失相位信息
- FROG在每个延迟点额外测量光谱分布（ω维度），从而能够重构完整的复电场 E(t) = A(t)·e^(iφ(t))，包括幅度和相位

**数学关系：**
FROG trace: I_FROG(ω, τ) = |∫ E_sig(t)·e^(-iωt) dt|²
其中 E_sig(t) = E(t)·E(t − τ)（SHG-FROG的门函数取法）

---

⚙️ **实验装置 | Experimental Setup**

```
激光器
  ↓
分束器 (50:50)
  ├─→ 反射镜 M1
  │      ↓
  │   延迟线（步进电机，精度~0.1 fs/步）
  │      ↓
  │   反射镜 M2 ─────────────────┐
  │                              ↓
  └─→ 反射镜 M3 ──→ BBO非线性晶体（~100 μm厚，Type I/II相位匹配）
                       ↓
                    滤波片（滤除基频光）
                       ↓
                    光栅光谱仪（CCD探测器）
                       ↓
                    计算机采集
```

**各元件作用：**
- **分束器（BS）**：50/50分光，确保两束功率相等
- **延迟线（Delay Stage）**：精密平移台，控制两束光的光程差，扫描τ ∈ [-T, +T]
- **BBO晶体**：β-BaB₂O₄，Type I（oo→e）或 Type II（oe→e），选择相位匹配角 θ ≈ 29°（800nm基频）
- **滤波片**：RKEL边缘滤光片，仅让SHG（ω→2ω）通过
- **光栅光谱仪**：300-600 g/mm光栅，分辨率~0.1 nm，配备冷却CCD

---

🛠️ **操作步骤 | Step-by-Step Procedure**

**Step 1 — 光路对准**
1. 打开激光器，测量平均功率，确认脉冲参数
2. 用光束质量分析仪粗对两束光，确保两束严格平行且高度一致
3. 将BBO晶体放置在两束交叠位置，用红外卡或功率计微调晶体角度，找到SHG信号最强点（相位匹配角）

**Step 2 — 寻找零延迟（Critical Zero Delay）**
1. 关闭光谱仪门控，用快速光电二极管监测SHG信号
2. 缓慢扫描延迟线，当两束脉冲在时间上完全重叠时，SHG信号出现尖锐峰值
3. 用纳米级步进精确定位峰值中心，记为零延迟 τ = 0
4. **⚠️ 常见错误**：延迟线方向搞反 → 信号峰值的符号含义相反，导致相位重构符号错误

**Step 3 — 采集FROG Trace**
1. 设置延迟范围：通常扫描 ±(2~3)×脉冲半高宽对应的光周期
2. 设置步进：每步 ~0.1~0.5 fs（过采样比>2更好）
3. 每个延迟位置采集完整光谱（积分时间 10~100 ms，平均3~5次）
4. 构建三维数组 I_FROG(ω, τ)

**Step 4 — 数据反演（Retrieval）**
1. 初始化猜测 E(t)（通常为高斯或待测脉冲估计）
2. 迭代循环：
   - 计算 E(t) 的FROG trace（前向传播）
   - 与实测trace比较，计算误差
   - 使用PCGPA（Principal Component Generalized Project Algorithm）更新E(t)
   - 重复直至收敛（误差<阈值，通常<0.01）
3. 输出重构的脉冲电场 E(t) = A(t)·e^(iφ(t))
4. 计算脉冲宽度（FWHM）、相位、瞬时频率等参数

---

📊 **数据处理 | Data Processing**

```
实测FROG trace I_meas(ω, τ)
        ↓
初始化 E(t) = A(t)·exp[i·φ(t)]
        ↓
迭代重构循环：
  E_sig(t, τ) = E(t) · E(t-τ)  [SHG-FROG]
  I_calc(ω, τ) = |∫ E_sig(t, τ)·e^(-iωt) dt|²
        ↓
  误差 = Σ|I_meas - I_calc|²
        ↓
  更新E(t)（共轭梯度投影）
        ↓
  收敛？ → 输出E(t)
        ↓
最终结果：
  ├─ 脉冲时域轮廓 |E(t)|²
  ├─ 相位 φ(t) → chirp分析
  ├─ 瞬时频率 ω(t) = ω₀ + dφ/dt
  └─ 频域光谱 |Ẽ(ω)|²
```

⚠️ **局限性与常见坑 | Limitations & Pitfalls**

**FROG的局限性：**
1. **时间窗口有限**：通常只能测 ~100-200 fs，无法直接测量<5 fs的脉冲
2. **晶体相位匹配带宽**：BBO带宽极限 ~5-10 fs for 800 nm
3. **噪声敏感**：SHG效率低（10⁻⁴~10⁻³），低信号时噪声严重影响重构精度
4. **高阶效应**：强非线性可能导致晶体损伤或饱和，扭曲FROG trace

**实验中最常出的问题：**
| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 找不到零延迟 | 光路不等长、晶体未相位匹配 | 重新对准，用二极管扫描找峰值 |
| Trace变形/不对称 | 晶体角度偏离相位匹配角 | 微调晶体θ和φ角 |
| 重构不收敛 | 初始猜测太差或噪声太大 | 用更准确的初始估计，降低噪声 |
| 脉冲宽度比预期长 | 延迟线行程不够 | 延长延迟范围 |
| SHG信号弱 | BBO晶体老化/污渍 | 清洁或更换晶体 |
