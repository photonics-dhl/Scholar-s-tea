📖 超快光学知识 — **SPIDER（光谱相位干涉仪）**

---

🔬 **原理**

SPIDER（Spectral Phase Interferometry for Direct Electric field Reconstruction）通过**自相位调制（SPM）**产生两束频谱剪切（spectral shear）后的脉冲，再利用**光谱干涉**提取相位信息。

核心思想：将待测脉冲与自身经色散后的拷贝在频域叠加，两束光因群延迟不同产生干涉条纹，相位差正比于光谱相位对频率的二阶以上导数（即群延迟色散GDD、TOD等）。

关键方程：
- 干涉信号：$S(\Omega) = |E(\Omega)|^2 + |E(\Omega + \Delta\Omega)|^2 + 2|E(\Omega)E(\Omega + \Delta\Omega)|\cos[\phi(\Omega + \Delta\Omega) - \phi(\Omega) + \omega\tau]$
- 其中 $\Delta\Omega$ 是 spectral shear（频谱剪切量），$\tau$ 是两路间的相对时延
- 展开相位差：$\Delta\phi(\Omega) \approx \tau \cdot \Omega + \text{GDD}\cdot\Omega\Delta\Omega + \cdots$

SPIDER测量的是**光谱相位差的余弦**，本质上是一个一阶相位测量技术——它无法直接测量脉冲包络，只能通过相位积分还原时域波形。

---

⚙️ **实验装置**

两种主流构型：

**（A）共线SPIDER（经典构型）**

```
Laser Pulse → 分束片(BS)
                ├── 主路 → 脉冲①（延迟τ）
                │         ↓
                │    BBO晶体（SPM非线性）→ 光谱仪
                └── 参考路 → 脉冲②（无SPM，chirp版）
                           ↓
                        棱镜/光栅（引入色散）

最终：脉冲① + 脉冲② 同时进入光谱仪 → 干涉图样
```

**（B）干涉仪式SPIDER（更常用）**

```
Pulse → 50:50 BS
         ├── 臂1：延迟线τ → 非线性晶体（BBO）产生SPM脉冲
         └── 臂2：色散元件（玻璃/光栅）→ chirped参考脉冲

两路在输出端通过第二块BS合束 → 光谱仪检测干涉
```

**光谱剪切 $\Delta\Omega$ 的产生**：在BBO晶体中，脉冲经历SPM时，其瞬时频率随时间变化 $\omega(t) = \omega_0 + \phi'(t)$，相当于在频域将原谱"剪切"了一份偏移量 $\Delta\Omega$。

**关键器件**：
- BBO晶体（通常0.1-0.5mm厚，角度相位匹配）
- 光学延迟线（分辨率需~0.1fs，用于寻找$\tau$）
- 光谱仪（高分辨率，0.01-0.1nm级别）
- 色散玻璃（SF11、BK7等，用于产生chirp参考）

---

🛠️ **操作步骤**

**Step 1：光路对准**
1. 先关闭非线性晶体，调节两臂光束，使其在输出端BS后完全重合
2. 用CCD观察干涉条纹——条纹对比度最高时表明两臂波前匹配
3. 恢复非线性晶体（BBO），对准晶体角度使相位匹配

**Step 2：零延迟与时延设置**
1. 移动延迟线，扫描$\tau$寻找零延迟（两臂脉冲完全重叠时的干涉峰）
2. 设置$\tau$为一个非零固定值（约脉冲长度的1-2倍），使干涉图样清晰
3. 注意：$\tau$过大导致干涉条纹过密（无法分辨），过小导致信号重叠

**Step 3：光谱干涉图采集**
1. 采集包含干涉条纹的光谱图
2. 典型图样：直流背景上叠加余弦条纹，条纹频率正比于$\tau$和GDD
3. 采集多组数据取平均，提高信噪比

**Step 4：相位提取（算法）**
1. 从干涉信号中提取相位差：$\cos[\Delta\phi(\Omega)]$
2. 使用傅里叶变换法（FT）：
   - FT→ 移动零点 → 滤波 → iFT → 得到相位
3. 积分得到光谱相位 $\phi(\Omega)$，再做逆傅里叶变换得到时域电场 $E(t)$

**Step 5：脉冲重构验证**
1. 重构后的脉冲与已知压缩结果对比验证
2. 可用二次谐波自相关（SHG AC）交叉验证

---

📊 **数据处理**

1. **原始数据**：光谱强度 $I_{\text{SPIDER}}(\omega)$ — 余弦条纹图样
2. **干涉项提取**：$I_{\text{interf}}(\omega) \propto \cos[\phi(\omega + \Delta\omega) - \phi(\omega) + \omega\tau]$
3. **相位差展开**：
   $$\Delta\phi(\omega) = \tau\omega + \frac{1}{2}\text{GDD}\cdot\omega\Delta\omega + \frac{1}{6}\text{TOD}\cdot\omega(\Delta\omega)^2 + \cdots$$
4. **逐项拟合**：用线性拟合提取$\tau$和GDD，高阶项通过迭代优化
5. **相位积分+逆FT**：得到 $E(t)$，计算 $|E(t)|^2$ 即脉冲强度包络

**常用算法**：LPF（低通滤波）、MIIPS（Multi-Impulse Intrapulse Interference Phase Scan）、直接相位提取

---

⚠️ **局限性与常见坑**

**局限性**：
- SPIDER只能测**已知**脉冲的相位细节，对完全未知脉冲有歧义（需要假设相位平滑）
- 对高阶相位（TOD及以上）敏感度下降
- 噪声放大：干涉信号中的小噪声经FT处理会放大
- 短于5fs的脉冲：SPM过程本身会改变脉冲谱，难以准确测量

**常见坑**：
1. **光束指向不稳定**：干涉条纹对比度下降 → 每次采集前检查指向
2. **非线性晶体角度偏离**：导致SPM效率低，剪切量不足 → 精细调节晶体角度优化信号
3. **延迟线回程差**：步进电机有机械回差 → 同一方向扫描，避免正反往返
4. **光谱仪饱和**：过曝导致干涉峰被截断 → 衰减光强或缩短积分时间
5. **两臂光束不重合**：干涉图样有莫尔条纹而非平行条纹 → 调节到完全重合
6. **Spectral shear方向判断错误**：导致相位积分符号错误 → 用已知chirp脉冲验证

---

🌟 **与洪亮研究的联系**

**ICS深亚周期脉冲诊断**：

1. **诊断需求匹配**：洪亮的ICS辐射脉冲预期为**深亚周期（<半光周期）**级别，传统SPIDER因光谱分辨率限制（$\Delta\Omega$ 需要足够小），对亚周期脉冲的诊断存在固有挑战——这正是需要**联合FROG+SPIDER**的原因

2. **Spectral shear的物理意义**：在ICS产生过程中，电子束与深亚波长场相互作用，电子的瞬时动量变化 $\Delta p(t) \propto E(t)$ 产生辐射，其频谱包含极宽的相位相干信息——SPIDER测量的相位差 $\Delta\phi(\Omega)$ 实际上反映的是辐射场的相位结构

3. **群延迟测量**：ICS脉冲的时空耦合（spatiotemporal coupling）是核心问题，SPIDER通过测量光谱相位可以反推电子束的时间-能量关联（energy-chirp），这对优化ICS辐射质量至关重要

4. **实验升级思路**：在ICS实验中搭建SPIDER诊断时，可将电子束分出一小部分作为"探测脉冲"，与主激光场做光谱干涉——这与洪亮 pump-probe 实验设计高度一致
